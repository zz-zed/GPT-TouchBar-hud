# 设计原则与实现边界

以下为本次升级的工作原则；HUD 已选定 Quiet；菜单已选定 Status-first；Touch Bar 已选定 Balanced，采用内容宽度信息列与两行点数区。

1. **一眼读懂。** 主信息回答“任务怎么样、还剩多少额度”；时间和账号统计依展示空间逐步展开。
2. **默认安静。** 背景保持克制；不做数字滚动、背景循环或额度条持续动画。
3. **状态准确。** 0%、未知、刷新中、旧数据明确区分；任务数不当作进度百分比。
4. **层次渐进。** 菜单栏给摘要，HUD 持续陪伴，设置承载完整偏好。
5. **内容驱动宽度。** Quiet 根据可见任务、额度及刷新按钮自动伸缩，不预留空任务区。保留等宽数字与一致间距；删除浮窗关闭按钮，隐藏由菜单提供。
6. **原生可用。** Swift/AppKit 保持现有栈，优先系统字体、原生菜单和可访问控件；网页磨砂只是视觉近似。
7. **保留控制权。** 刷新立刻反馈，通过菜单隐藏可恢复，拖动跟手，键盘操作不等待动画。
8. **同一状态语义。** 三界面复用现有状态源与统一展示语义，额度和任务色彩各有明确职责。

## 初始 token 草案

| 类别 | 草案 |
| --- | --- |
| 字体 | 系统字体；主数字 13–14 / semibold / monospaced digits；次信息 11–12；元数据 10–11 |
| 间距 | 4 / 6 / 8 / 12 / 16；由内容密度选择，不强行在三个界面共用同一外框 |
| 圆角 | 紧凑胶囊为半高；双层/卡片 16；按钮 7 |
| 材质 | 深色工具面板 + 细描边；减少透明度时实色；明暗桌面均验证 |
| 额度 | 正常数字白色，进度条低饱和青绿；紧张时数值与警示同步，不只变色 |
| 任务 | 执行青色、完成用勾号、空闲中性；文字辅助含义 |
| 操作 | 图标 26 点命中区域；可见 focus ring；刷新有进行中反馈 |
| 动效 | 数值/布局切换立即更新；按下反馈轻微缩放；Reduce Motion 关闭运动 |

这些值服务于原型探索，选定方向后再形成正式 Swift token。绝不把 HTML 的像素和 backdrop-filter 等同于 AppKit material。

## 工程范围

已有 `RateLimitDisplayState` 继续作为状态来源。优先抽取共享展示格式和 UI token；菜单组合可移出 AppDelegate，暂不移动整个 Sources 目录。保留数据解析、刷新退避、账号失效处理、常驻 Touch Bar 生命周期、偏好迁移和更新机制。

先实现静态层次和错误状态；动效最后处理。Motion 验收检查目的、频率、可中断性、Reduce Motion、不可见暂停及 CPU，不以“更生动”作为添加理由。

按以下阶段验证：共享展示规则 → HUD → Menu/Settings → Touch Bar。每一阶段构建、对应脚本回归和原生截图；最终覆盖系统控制条、跨 App、睡眠恢复及实体硬件裁切。网页原型与现有脚本通过都不能证明硬件行为。
