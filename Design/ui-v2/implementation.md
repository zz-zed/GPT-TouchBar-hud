# 原生实现交付

2026-09-17。本地实现基于用户确认的 Quiet / Status-first / Balanced，保留现有额度读取、账号 Token 用量、任务监控、Touch Bar 常驻和系统控制条生命周期。

## 界面变化

- Quiet：40 点高胶囊，任务、额度和刷新单行排列；移除关闭按钮，内容增减时自动调整宽度，隐藏入口在菜单中。既有外观偏好继续有效；新用户默认提高不透明度。
- Status-first：菜单顶部汇总额度、重置/到期时间、任务、Token 用量、点数与刷新状态；下方为原生操作。菜单栏保留横向闪电圆形图标及任务状态色，也保留重置卡外显。
- 设置：独立窗口，分通用、外观、Touch Bar 三页；颜色与不透明度即时保存，提供实时 HUD 预览。
- Balanced：30 点高，信息列按内容计算宽度，列内间距 6 点，保留 40 点进度条。昨日/累计始终上下排列，点数在有值时追加紧凑的两行区块。
- 反馈：刷新过程中按钮禁用；错误图标与提示保留；HUD 响应减少透明度及提高对比度偏好，任务动画继续遵守减少动态效果和可见性控制。
