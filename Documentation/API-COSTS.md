# API 消费统计

[返回 README](../README.md) · [数据与隐私](DATA-AND-PRIVACY.md)

API 消费是可选功能，默认关闭。设置沿用原有顶部标签页，新增「API 消费」，不增加组织选择或管理流程。

## 接入与操作

在「设置 → API 消费」输入具有费用查询权限的 Admin API key，点击「验证并启用」。应用先查询费用，只有完整验证成功且密钥成功保存到本机钥匙串后才启用。普通模型 API key 不保证有查询权限。

启用后，菜单栏摘要用一行显示本月 API 消费。菜单与刘海各在右上角将最后更新时间与刷新按钮并排显示，取当前已启用数据源中最近一次成功获取的时刻；刷新中保留上次时间，跨日时附日期。悬停消费金额可查看消费口径和该统计的获取时间。顶部「刷新」和 ⌘R 同时请求更新可刷新的数据，接入管理位于「显示与偏好 → API 消费设置」。刘海展开后的「用量」页分组展示 Token 与消费，底部「刷新全部」更新可刷新的来源，并保持忙碌状态直到请求结束。各来源的启停、冷却和限流规则分别生效。

密钥失效显示「密钥已失效 · 更换密钥…」，权限不足显示「无查询权限 · 检查权限…」，点击进入对应设置；网络和服务错误提供重试。金额保留同月上次完整统计，悬停消费金额可查看该统计的获取时间。额度及其重置时刻使用蓝色，可用重置及最早到期使用琥珀色，预告使用紫色，Token 使用青色，API 消费使用绿色。

- 「显示 API 消费」关闭后隐藏信息并停止刷新，保留接入配置。
- 「更换密钥」先验证候选密钥；失败保留原配置，原配置已经失效时仍需要修复。
- 「断开连接」经确认后移除本功能的钥匙串条目、偏好和内存中的统计。不会删除或撤销平台上的密钥。
- 关闭设置窗口或取消编辑会清空输入框并取消未完成的验证。

## 统计口径

数据来自官方 `GET https://api.openai.com/v1/organization/costs`。查询当前接入对应的全部 API 费用，不按项目或 API Key 筛选，金额可能包含多个项目及 Key 的消费。

按 UTC 自然月统计，从当月 1 日 00:00（包含）到本次查询开始时刻（不包含）。北京时间每月 1 日 08:00 进入新的 UTC 月份。费用按十进制金额汇总，只有全部分页有效时才发布结果；当前接受 USD 费用。

这项统计表示已报告的消费金额，不是充值余额、剩余预算或实时扣款。最近获取时间使用本机时区，仅表示完成查询的时间。官方接口没有在本功能所依据的文档中保证实时入账。

| 显示 | 含义 |
| --- | --- |
| `US$0.00` | 完整响应明确返回零费用。 |
| `< US$0.01` | 费用大于零，但不足一美分。 |
| 暂无消费记录 | 完整响应没有费用记录，不等同于已确认零消费。 |
| `—` | 还没有当前月份的有效统计。 |
| 更新失败／显示上次统计 | 当前查询失败，保留的是同一月份上次完整结果。 |

跨月后清空上月金额，重新获取本月统计。接口返回负金额时按带符号数值汇总，不擅自截为零；这不代表接口保证提供完整退款或余额调整流水。

## 刷新与运行边界

启用且 HUD 运行时，每 15 分钟重新查询当前整月费用。手动请求最短间隔 30 秒；失败按 1、5、15 分钟退避，限流时同时遵守 `Retry-After`。权限或密钥失效时暂停刷新，需在设置中修复接入。

休眠、锁屏或会话暂停时停止请求，恢复后按需刷新。统计不依赖 Codex 额度读取成功，但仍遵循应用原有启停规则：HUD 随宿主退出时也停止刷新。

## 隐私与存储

密钥由用户在应用中输入，只保存在本机 macOS Keychain，不通过 iCloud 同步。应用仅访问自己创建的指定条目，不枚举或读取其他凭据。查询使用固定官方 API 地址，不跟随重定向，不使用 URL 缓存、Cookie 或磁盘费用缓存。

偏好仅保存启用与已配置标记。消费快照只保存在内存，应用退出后清除；重启后重新查询。密钥、原始响应和费用金额不写入诊断日志，不新增远端埋点。卸载前可通过「断开连接」清理本功能的钥匙串条目。

## 验证边界

离线检查入口：`bash scripts/test-api-costs.sh`，也纳入 `scripts/test-core.sh`。使用合成 HTTP 响应、内存凭据替身与隔离偏好，不读取真实密钥、不连接真实账号。原生预览输出到 `.build/api-cost-ui-preview/`。

真实 Admin API key 权限、真实费用延迟、钥匙串系统授权行为和实体刘海显示仍需单独验收。离线测试通过不代表这些检查已完成。

依据：[Costs API](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)、[Admin APIs](https://developers.openai.com/api/docs/guides/admin-apis)。
