# v0.1.44 发布记录

2026-10-13。GPT TouchBar HUD v0.1.44 / Build 47 汇集已合入 main 的 Touch Bar 预告数量样式、任务监控 CPU 优化及任务恢复修复，并纳入此前仅在本地保存的自动更新退出修复。当前为发布准备记录，正式发布时间、源码提交及公开验包结果将在发布后补齐。

## 变更

- 自动更新退出：通过主 RunLoop 在 AppKit 终止等待模式中交付缓存与诊断落盘完成回调；完成、截止与迟到回调共享一次完成保护，退出等待仍有 3 秒上限。消息缓存的读取、写入和 flush 回调使用同一投递方式，避免 flush 抢在写入确认前完成。原生回归从主队列调用真实 `NSApplication.terminate`，覆盖正常完成、写入不响应、迟到及重复完成。
- 任务监控：不可读日志使用退避重试，避免将历史缺失路径当作真实字节积压；无变化的断点不重复编码写盘。保留读取预算、公平调度与新事件处理。
- 任务恢复：恢复须具备同一轮次的明确开始依据，校验日志身份与断点，补读到完整记录边界；终态优先否决。旧缓存须重建开始依据；历史完成不重放提示，已结束轮次不能被迟到事件或重复开始复活。
- Touch Bar：以数量徽标突出有效重置预告，保留原生点击、动作与辅助功能。
- 发布流程：按范围选择开发检查；正式发布仍复用同一 main 提交、同次完整双架构构建，校验来源、摘要、附注标签及公开产物。

相关记录：[退出修复](UPDATE-EXIT-FIX-2026-10-12.md)、[CPU 对照](TASK-MONITOR-CPU-FIX-2026-10-13.md)、[任务恢复与安装验证](TASK-MONITOR-INSTALLED-VALIDATION-2026-10-13.md)、[CI 与发布](CI-AND-RELEASE.md)。

## 本地验证

- 更新策略及隔离安装保护：82 项与 42 项检查通过。
- 原生退出：4 个独立 AppKit 进程场景通过。
- 诊断恢复：25 项检查通过；诊断安装器：139 项检查、12 个实际脚本场景通过。
- 更新进度：223 项检查通过，使用回环下载、隔离助手和原生窗口。
- 消息缓存、通知及运行时：453 项检查通过，网络和通知使用注入夹具。
- 发布、CI 策略、构建范围、Gate 和来源拒绝规则：8 组共 122 项离线测试通过。

整合时消息运行时回归曾发现 flush 与写入确认使用不同投递方式，导致通知检查提前结束；改为同一主 RunLoop 投递后，完整运行时回归通过。原始失败与最终成功日志保留在本地 `build/release-evidence/v0.1.44/`。

## 验证边界

任务恢复依据本机日志，沿用 30 分钟证据时效，不代表宿主直接提供的执行真值。系统睡眠时长补偿、更强的来源进程身份适配、长期能耗及真实 macOS 11 尚未完成验收。CPU 数据来自相关记录中的同机短时对照，不承诺所有机器均得到相同降幅。

安装包使用 ad-hoc 签名，未经 Apple 公证。发布验包只读挂载 DMG，不修改本机已安装应用；双架构构建通过不等于所有机型的运行验收。
