## 变更

- 自动更新退出：通过主 RunLoop 在 AppKit 终止等待模式中交付缓存与诊断落盘完成回调；完成、截止与迟到回调共享一次完成保护，退出等待仍有 3 秒上限。消息缓存的读取、写入和 flush 回调使用同一投递方式，避免 flush 抢在写入确认前完成。原生回归从主队列调用真实 `NSApplication.terminate`，覆盖正常完成、写入不响应、迟到及重复完成。
- 任务监控：不可读日志使用退避重试，避免将历史缺失路径当作真实字节积压；无变化的断点不重复编码写盘。保留读取预算、公平调度与新事件处理。
- 任务恢复：恢复须具备同一轮次的明确开始依据，校验日志身份与断点，补读到完整记录边界；终态优先否决。旧缓存须重建开始依据；历史完成不重放提示，已结束轮次不能被迟到事件或重复开始复活。
- Touch Bar：以数量徽标突出有效重置预告，保留原生点击、动作与辅助功能。
- 发布流程：按范围选择开发检查；正式发布仍复用同一 main 提交、同次完整双架构构建，校验来源、摘要、附注标签及公开产物。
