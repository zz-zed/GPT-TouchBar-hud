# M1 升级连续性复审记录

2026-10-08。范围为升级协议与多进程存储、旧 HUD 交接、真实安装脚本点位、新 HUD 接续、任务观察链路、冻结导出及记录控制。与初次 M1 的复审和证据分别保存。未启动、安装或替换正式/试用 App。

## 发现与修复

| 问题 | 最小修复 | 验证依据 |
| --- | --- | --- |
| 持久关闭遇到跨进程锁忙，原 void callback 仍可能被 UI 当成全局关闭成功 | 新增明确 Result，后台最多 500 ms 重试；UI 仅在持久成功后写偏好，失败保留跨进程未知与重试入口 | 存储 reporting 测试；导出/UI 锁占用、释放后重试检查 |
| captureSnapshot 被 clear 使代次失效，导出可能转成可保存的“读取失败”部分快照 | cancelled 直接映射 invalidated，不重新盖当前代次 | 导出/UI 跨代取消回归 |
| 恢复事件与普通事件使用两组生产者会话及序号，不利于真实进程对照 | 新/恢复 HUD 经锁内 epoch 与 generation 校验后，全部使用普通 Recorder；助手保留独立轻量写入器 | 恢复身份测试、存储接续代次测试 |
| Hooks 接受新开始事件但汇总计数相同，可能缺少同批次聚合与显示链路 | 开始观察先于对应 snapshot；只对有明确开始证据的那次强制完整诊断批次，稳定重复仍静默 | 合成同计数集成回归；真实临时文件/socket 的 Controller 回调顺序测试 |
| prepareUpgradeHandoff 在 clear 提升代次后，仍可能把旧升级关联写回 | 调用时锁内捕获代次并入队；后台在持久控制临界区内读 epoch，赋值前再次检查代次、启用与启动状态 | 确定性写入 gate：旧实现先失败，修复后 132 项升级存储检查通过 |

最后一项明确竞态发现后，中止并标记当时的回归轮次为 superseded；交付验证从修复后的源码摘要重新开始。未把上一轮通过的日志或旧试用包冒充追加范围的结果。

最终回归中，Touch Bar 测试有一次前台 PID 比较失败。原断言用测试开始时的 PID 对照多次事件循环后的激活动作，受期间桌面焦点变化影响；已将该项收窄到目标调用前后比较，生产激活代码没有修改。保留首次失败日志和重跑结果，未把隔离检查当作实体 Touch Bar 验证。

## 证据语义

- 实际安装脚本隔离测试执行生产脚本函数和复制的诊断 CLI，仅替换 OS 文件操作/启动/等待为自有测试动作。12 类场景、138 项检查覆盖正常、退出超时、备份/替换/启动失败、回退、无回执/迟到回执、诊断失败/超时和无旧版诊断能力。
- 存储使用真实自有子进程验证并发容量、锁竞争和清除后旧助手不复活；写入失败与磁盘满采用注入，不宣称实际填满磁盘或断电。
- 25 项恢复检查覆盖身份/路径/版本、唯一与歧义候选、回退、清除代次、连接与读取/任务开始分别观测，以及单一退出截止时间和至多一次 AppKit reply。
- 导出专项包括冻结内容与独立 unzip 校验、锁与跨代失败、来源/目标版本、生产者覆盖、范围截断、缺边界及回拨时钟。未知协议/事件安全跳过；不会原样复制未知 JSON 或私有交接路径。
- 运行中任务模式、宿主运行观察与宿主是否同一进程分开。后者未实现私有 PID 加启动时间比较，明确保留 unknown。

当前完整测试、构建输入摘要、App 签名/架构/minOS、原工作区与旧 App 保留核对见 [diagnostics-m1.json](diagnostics-m1.json)。原生窗口截图使用合成环境，不是 Intel 或 macOS 11 真机运行证据。

## 保留的限制

真实升级/回退、持续运行 Codex、实体 Touch Bar/刘海/无 Touch Bar、多屏、休眠、macOS 11、故障系统、Intel 链接与三轮 10 分钟 CPU/内存对照未执行。非阻塞锁或写入失败仍可能失去记录；导出明确缺口，不能承诺零丢失。跨进程时钟不能用于精确连续计时；摘要仅展示可比较的观察边界。没有诊断能力的来源程序和助手不能补回历史。
