# M1 独立审查记录

2026-10-08。本轮在独立工作树进行源码只读复核和临时目录探针验证，未启动正式或试用 App，未访问真实账号、会话数据或 LaunchAgent。

审查关注字段白名单、存储恢复、关闭/清除代次、导出一致性和原业务控制流。发现并修复三项问题：

| 问题 | 修复 | 独立复验结果 |
| --- | --- | --- |
| 事件文件部分写入后，记录的文件大小与实际大小不符，后续写入持续拒绝 | 追加失败时放弃当前文件，下一次写入新 UUID 文件，保留坏尾行和缺口 | 注入半条尾行后，首次拒绝；后续两次成功，快照含 3 条有效事件及 corruptedLine |
| 当前事件文件被 FIFO 替换后，追加打开可能阻塞串行队列 | `O_NONBLOCK` 打开并检查普通文件及硬链接数 | 无读端时在 1 秒内返回错误 |
| 全新记录器以关闭状态启动，不维护已有事件文件的到期清理 | 禁用状态仅维护已存在目录的保留期限；不创建缺失目录、不写新会话标记 | 2 秒保留期 / 等待 3 秒后过期文件为 0，旧标记字节不变，缺失目录仍不存在 |

原始只读探针副本见 `diagnostics-m1-evidence/TailProbe.swift` 和 `BoundariesProbe.swift`；其中临时目录为当次实际测试路径，不应直接复用于生产数据。可重复的隔离回归已纳入 `Tests/DiagnosticRecorderTests.swift`，通过正式诊断测试脚本运行。

另外在集成审查中修复：初始存储失败退避、追加前容量预算、持续写入文件的物理过期淘汰、父目录符号链接拒绝、同进程单调耗时、损坏/篡改字段重建、缺口计量单位、读取快照与清除交错的代次、导出取消后的单操作槽及跨卷安全保存边界。没有新增任意文本日志入口；业务任务激活条件、重连退避和显示接口调用策略保持原控制流。

有限审查覆盖内未发现剩余重要问题；这不替代真实 Intel / Apple Silicon Touch Bar、刘海、多屏、休眠、macOS 11 及三轮空闲 CPU / 内存对照。独立探针使用合成数据，其中半行测试模拟部分写入状态，不声称在真实磁盘满设备上复现。
