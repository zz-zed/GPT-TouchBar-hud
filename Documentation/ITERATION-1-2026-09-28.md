# 第一轮产品迭代：额度提醒、连接诊断与启动控制

2026-09-28。本文描述当前源码的开发改动，尚未公开发布。独立测试包沿用 0.1.35 / Build 38 版本标记，不代表 GitHub 的 v0.1.35 安装包已包含这些能力。

## 已实现

### 个人低额度提醒

入口：设置 → 额度提醒。

- 默认关闭。5 小时与每周额度分别设置剩余阈值，可选 10%、20%、30%、50%，默认均为 20%；提示音默认关闭。
- 开启后的第一组有效数据静默建立基线。之后，同一账号、同一额度周期内，剩余比例从阈值以上降至阈值或以下时提醒一次。点击通知打开额度提醒设置。
- 每次额度读取前后复核账号，只有身份一致的成功快照才参与提醒。缺少账号元数据的旧宿主仍可展示实时额度，但不触发提醒；读取期间切换账号会丢弃该组结果。
- 错误、缺失或无效重置时间、过期数据不触发提醒。休眠、锁屏、用户会话暂停、关闭提醒及阈值修改后重新建立基线；重复刷新不重播。
- 去重跨 App 重启保留。权限拒绝或系统投递失败后不补发本周期的旧提醒；每次打开设置会重新读取系统权限。
- 与公开重置预告分别配置，共用系统通知入口，保持各自的点击处理。

此批只实现低额度提醒。额度恢复提醒、重置卡到期提醒与历史趋势属于后续范围。

### 连接检查与脱敏诊断

入口：设置 → 通用 → 连接检查与诊断。

检查宿主内置程序、连接、登录状态、额度接口与 Token 接口，结束前再次核对账号。额度和 Token 分别报告，单项接口失败不会覆盖另一项已经取得的结果。检查期间账号变化时，相关结果作废。

检查仅在主动打开诊断或点击“重新检查”时运行，使用独立的短时连接，结束或关闭窗口后断开。运行期间不可复制；结束后可审阅完整报告，再点击“复制诊断信息”。应用不会自动发送报告。

报告仅包含 App 版本、macOS 版本、架构、宿主名称与版本、检查时间、固定状态及恢复建议。不包含邮箱、账号原文、用户目录、凭据、原始服务端错误、具体额度或对话。没有原始文本拼接后再做替换的脱敏路径。

### 永久关闭随宿主启动

入口：设置 → 通用 → 随 ChatGPT / Codex 启动。

未保存过偏好的用户沿用开启行为。关闭时停用本工具的注册项，确认服务已卸载并移除对应注册文件后，保存关闭状态；失败会回显实际开关状态和原因。之后手动打开应用仍保留关闭选择。重新开启会恢复注册。

保留现有“手动退出后，本轮宿主会话内不再自动拉起”的行为。此开关控制自动拉起；已运行 HUD 的宿主退出联动保持原有行为。

## 本地数据

| 内容 | 保存方式 |
| --- | --- |
| 自动启动偏好 | UserDefaults 的 `hostAutoLaunchEnabled`，缺省为开启。 |
| 提醒开关、阈值、提示音 | UserDefaults 的 `quotaAlertsEnabled`、`quotaAlertsFiveHourThreshold`、`quotaAlertsWeeklyThreshold`、`quotaAlertsSoundEnabled`。 |
| 提醒去重 | `quotaAlertsDeduplicationV1`：仅保存账号及周期组合的哈希、重置时间和记录时间，最多 512 条、最长 90 天；周期到期 24 小时后可清理。不保存邮箱、原始身份或用量曲线。 |
| 诊断报告 | 窗口内存；仅用户点击复制后写入系统剪贴板，不自动存盘或上传。 |
