## 正式发布门禁

1. 推送发布提交到 `main`，等待同一提交的 Apple Silicon、Intel 数据与界面回归、构建和产物上传全部成功。
2. 固定上述提交的完整 SHA，推送指向该提交的 `v0.1.37` 注释标签；发布工作流复用并核验同一来源、同一轮次的双架构产物。
3. 确认正式 Release 公开、非预发布且为 Latest，正文与标签提交中的 `RELEASE_NOTES.md` 一致。
4. 使用 `scripts/verify-public-release.py` 重新下载四份公开附件，核验来源、大小、SHA-256、校验文件、清单、DMG 完整性和只读挂载、版本、架构、最低系统标记、严格签名及首次打开助手 CDHash 绑定。
