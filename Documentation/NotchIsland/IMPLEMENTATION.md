## 必须落地的结构

1. 固定尺寸透明非激活 NSPanel，内部 NSHostingView / SwiftUI。窗口大小只因屏幕、配置或预先测量变化更新，不在动画中逐帧改系统窗口 frame。
2. Compact / Peek / Expanded 显式状态机。Compact 为左右小翼；Peek 横向露出额度与重置摘要，原有两侧标记的物理位置不移动；点击 Compact/Peek 展开详情；离开完整交互面后回到静止态。新增“始终显示额度”选项时，开启后的静止态为 Peek。首次默认 Compact，现有显示模式等偏好不重置。
3. 单一动画几何同时控制外壳、裁剪和鼠标命中。使用动画实际呈现值回传 AppKit，不允许另起近似计时曲线推算点击区域；指针静止时也必须随形变刷新穿透。
4. 点击区域、悬停维持区域、装饰区域分离；透明区域、圆角外部、摄像头避让区和装饰穿透。摄像头间隙可以帮助维持悬停，但不能拦截点击。外部点击收起并送达下面的 App。子菜单/弹出层打开时维持展开。
5. 完整动画节奏采用参考正文：展开 .42/.82、收起 .30/.88 弹簧；点击时外壳立刻展开，详情 220ms 后进入，预览胶囊 250ms 时退出；收起时内容立刻退出，20ms 后外壳收回。保留退出层至淡出结束。页间切换仅移动中部内容。
6. 中央可取消延迟调度，使用递增世代号或等价机制防止快速 A→B→A→B 时旧动作生效。隐藏、锁屏、屏幕变化和销毁取消后续动作。数据刷新不得重启动画或修改用户展开意图。
7. Expanded 保持固定头尾、中间额度/活动/用量三页；使用现有真实数据能力，缺少图表历史时不添加虚构图表、假计费或另一套数据源。详情空白区域不执行展开切换。
8. 全流程不在悬停、展开或刷新时激活 App 或抢键盘焦点。设置等明确操作沿用现有行为。无全局键盘截获。
9. 减弱动态效果、减弱透明度、低功耗和不可见状态有对应降级；动画刷新局限于需要的子视图。内部开关可退回 legacy，但不得同时显示两套窗口。
10. 屏幕几何分离物理遮挡与视觉高度，包含坐标、notch center/width、physical top inset、visual bar height、backing scale。参考尺寸与 -1pt 规则是可校准参数；小屏、无刘海和外屏须使用有边界的布局，不可越界或把辅助区域当作空菜单栏。

详细尺寸、排版、颜色、动画曲线与时序以参考正文为准。800pt 详情 / 900×360pt 承载窗口是基准，必须考虑屏幕边界与实际内容；不照搬固定值导致内容裁切。

## 协调任务补充核对：上游不能直接照抄的部分

本轮通过 GitHub API 读取了上述固定提交的四个相关源码文件与 LICENSE，核对结果如下：

- 上游 `IslandWindowController.swift` 在 show 和鼠标进入时调用 `NSApp.activate`，进入时还会 `window.makeKey()` 并安装 Cmd+Q 按键监听。本项目必须保留自身非激活窗口行为，不引入这些调用。
- 上游 `IslandHostingView.hitTest` 与 window passthrough 使用 `model.size` 的矩形。它不能直接满足本次要求的动画实际轮廓、圆角、摄像头排除区和静止指针随轮廓变化的命中检查。
- 上游 `IslandRootView.swift` 的多个 `DispatchQueue.main.asyncAfter` 只判断当前状态/hover，不能排除经历往返后回到相同状态的旧回调。因此本项目需要集中取消与世代检查，不能仅复制这些 guard。
- 上游 LICENSE 为 MIT，版权行为 `Copyright (c) 2026 Eric Park`；如复制或改编实质源码，第三方声明应保留完整许可与该版权行并进入 App bundle。
- 本项目候选的 CI 文件确认是 `.github/workflows/build-dmg.yml`，已有 `scripts/test-notch-hud.sh`。后者以 `Sources/*.swift` 除 main 外的源码编译原生测试；专用新测试应与这一现有入口协调，避免建一套脱离打包的验证路径。
