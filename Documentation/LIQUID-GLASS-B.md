# Liquid Glass B：本地迭代记录

日期：2026-10-03。分支：`codex/liquid-glass`。基线：`5e1212a`（v0.1.37 / Build 40）。

本轮完成已确认的分层材质适配，交付独立工作树、原生演示和 arm64 候选包。改动尚未提交、合并、安装或发布；主工作区的更新进度迭代未被改动。

## 已实现

- **桌面浮窗**：macOS 26 及以上使用一层 `NSGlassEffectView` Regular 材质，保持 40 点高度。原控件放入 `contentView`；文字使用系统语义颜色和完整不透明度。刷新和预告按钮保留原图标、点击回调，并增加轻量悬停反馈。
- **刘海展开态**：黑色主体和硬件避让轮廓保持原逻辑。页签与底部操作各使用一个共享玻璃胶囊，选中项使用薄填充。玻璃模式关闭外围蓝色光晕及扫光，普通数据更新不改变展开状态。
- **外观偏好**：新增“跟随系统 / 经典外观”。新用户跟随系统；已有颜色或透明度键的升级用户保留经典。切换材质保留经典数值；原生玻璃可用时禁用经典颜色与透明度控件，并说明适用范围。
- **辅助功能与兼容**：减少透明度或增加对比度时使用实色表面；减少动态效果时取消手工缩放反馈。较旧系统使用经典外观，最低构建目标保持 macOS 11。
- **系统界面**：菜单和预告弹窗继续使用原生背景，未增加重复玻璃层。菜单、预告数量、完整重置次数及 Token 的数据语义保持原实现。

保留 `bolt.horizontal.circle.fill`、自定义箭头加时钟预告图标、`arrow.clockwise`，以及菜单中的 `gauge.medium`、`cpu` 等符号。没有使用设计原型里的替代图标。

切换材质时只重建背景和内容包装层，保留原按钮与内容栈。原生目视检查发现的经典回退文字下移问题已修复，并增加对齐矩形断言。演示窗口切换模拟屏幕尺寸时会重新创建宿主，避免场景中移动嵌入视图留下旧裁剪；产品刘海几何没有因此改写。

### 闲置对照

同一个预览进程、相同数据和窗口布局，各静置 15 秒：经典模式 CPU 累计时间为 `0:01.36 → 0:01.36`，玻璃模式为 `0:01.52 → 0:01.52`。在 `ps` 的 0.01 秒显示精度内均未增长。代码没有新增闲置帧循环。

这是一轮短时应用进程采样，不包含 WindowServer、GPU、唤醒次数或长期能耗。原始记录及构建摘要见 [验证记录](validation/liquid-glass-b.json)。

## 本地体验

在此工作树根目录执行：

```bash
bash scripts/test-hud-material.sh --preview
```

预览可切换材质、明暗、中英文、窄屏和刘海实色回退。“真实浮窗”打开正式透明面板；在面板上右键选择“返回原生预览”。“外观设置预览”使用正式设置控制器，但不会保存到实际用户偏好。

本地候选文件：

- `build/Liquid Glass Candidate.app`
- `dist/Liquid-Glass-B-arm64-candidate.zip`
- `dist/Liquid-Glass-B-arm64-candidate.zip.sha256`

候选保留基线版本号，以文件名标识本次未发布迭代。它未替换当前安装；预览应用使用独立标识。

## 验收边界

- 本机尝试了双架构构建；x86_64 在链接时缺少 `swiftCompatibility56`、`swiftCompatibilityConcurrency` 等兼容库，因此交付包仅含 arm64。该失败不能作为 Intel 产品回归或 Intel 验收结果。
- CI 显式选择 Xcode 26.3，防止 macOS 15 镜像默认的 Xcode 16.4 将玻璃实现编译为回退路径。此变更通过离线规则检查，尚未运行远端双架构 CI。
- macOS 26 与较旧系统的实际运行、实体刘海接缝、实体 Touch Bar、全屏、多屏和唤醒仍需分别验收。可用性分支、最低系统标记和合成屏幕测试不能替代这些检查。
- 未进行全背景范围的文字对比度测量、GPU 或长期能耗测量。本轮依据原生明暗画面修正了操作文字的语义颜色。
