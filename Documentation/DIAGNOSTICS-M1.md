# 本机诊断与反馈

应用提供可审阅的本地诊断包。它帮助对照连接、休眠与恢复、任务状态和显示请求的时间线，不会自动判断根因，也不会自动上传。

## 使用

在“设置 → 通用 → 诊断与反馈”打开诊断窗口。打开窗口只读取环境、已有检查和本地记录；“检查当前状态”才建立独立的短时诊断连接，不会重启 HUD 或宿主。检查结果与生产连接事件分别标记。

选择最近 30 分钟、最近 2 小时或全部可用记录，按需填写问题描述和发生时间，然后生成预览。描述不要包含账号、凭据或对话内容；这部分只进入本次可审阅的快照，不进入常驻事件文件。预览冻结后，继续产生的新事件不会混入保存内容。修改范围或描述后需重新生成预览。

可逐一查看以下五个文件，再通过保存面板保存 ZIP：

| 文件 | 内容 |
| --- | --- |
| `summary.txt` | 环境与检查摘要、匿名任务成员变化及读取原因、显示消费、升级恢复、问题描述、时间范围和缺口 |
| `environment.json` | 受限环境字段及每项 known / unknown 状态 |
| `events.jsonl` | 范围内的类型化事件，按进程随机会话号和序号辅助排序 |
| `checks.json` | 已有主动检查与起止时间；未执行时明确标记 |
| `manifest.json` | 包版本、范围、缺口、逐任务快照完整性、升级生产者覆盖和协议兼容情况、其他四个文件的大小与 SHA-256 |

保存成功仅表示 ZIP 已写入并经过基础可读性检查，不代表任何实体设备验证通过。为保证异常退出后的临时文件可在自有目录清理，ZIP 先在诊断目录暂存，再原子移动到保存位置；跨磁盘保存会提示先保存到用户资料所在磁盘，再用 Finder 移动。

## 保存范围与控制

基础记录默认开启，仅保存在 `~/Library/Application Support/GPT TouchBar HUD/Diagnostics/`。事件最多保留 72 小时，合计最多 10 MiB，普通单文件最多 1 MiB；每次升级的专用记录和私有交接信息另外共限 64 KiB，并计入同一个 10 MiB 预算；事件队列最多 512 条且不超过 1 MiB，单事件不超过 4 KiB。文件读写和导出在后台进行，队列满或写盘失败会形成可报告的缺口。清单分别计量确切丢弃事件、写入结果未确认的事件和缺口发生次数；无法读取记录时计数为未知，不填为零。应用运行时按最老记录的到期时间安排一次性清理；应用未运行时，在下次启动清理过期记录。

“关闭记录”通过持久控制状态停止 HUD 和安装助手的新事件；界面只有在持久更新成功后才确认完成，失败会明确提示助手状态未确认。应用不另行镜像到系统日志。关闭后保留尚未到期的已有文件；显式检查和导出仍可使用。“清除记录”使旧预览失效，只清除本应用识别的诊断材料。它不删除业务缓存、Hooks、更新恢复材料、用户另存的 ZIP 或操作系统已经收到的日志。清除会更换持久代次，旧安装助手不能重新创建被清除的历史。关闭和重新开启不会清除仍在保留期内的记录。

导出同一时刻只进行一次，采集与打包设有 30 秒截止时间，快照与 ZIP 的合计预算为 25 MiB。取消、保存失败和部分采集失败分别显示；部分失败不会被解释为“没有事件”或“没有任务”。

## 证据边界

- Touch Bar 的事件只能证明能力判断、接口调用或请求被跳过，无法证明物理屏幕已经显示。
- 刘海的 visible 表示 AppKit 可观察窗口状态，不等于用户目视确认。
- 任务计数来自生产判断流程；读取失败和无证据保留未知，成功空结果才可为零。诊断不会改变任务激活条件或终态判断。
- 进程随机会话号、连接代次和扫描批次用于观测对照；随机升级 ID 将有关进程连接到同次升级；不创建长期设备或账号追踪标识。
- 上次正常关闭的记录只表示曾进入尽力保存的退出流程。缺少标记称为“未确认正常结束”，不能判定崩溃。
- 不收集崩溃报告或原始对话，也不执行限时详细内容采集。

## 应用无法启动时

1. 在 Finder 中按 **Shift–Command–G**（前往文件夹）。
2. 输入 `~/Library/Application Support/GPT TouchBar HUD/Diagnostics/`。
3. 只复制根目录的 `events-*.jsonl` 和 `updates/<UUID>/writer-*.jsonl` 到自己选择的位置，审阅后按需发送。不要复制 `handoff.json`、`control.json`、锁文件或整个目录。

这属于应急原始记录，不是完整的冻结预览包，也不包含新的当前检查结果。没有目录或事件文件，可能是未运行过此版本、关闭了记录、已清除或写入失败，不能当作故障未发生。不要复制整个 Application Support、Codex 会话目录、账号文件或系统 DiagnosticReports 目录。

## 字段白名单

公共字段：schemaVersion、UTC 时间、进程随机 sessionID、会话 sequence、单调时钟毫秒、固定 module / severity 和类型化 event。时间调整不改变单调耗时；不同进程的耗时不可连续相减。

| 类型 | 允许的值 |
| --- | --- |
| 环境 | 受限数字版本、Build、构建源摘要、系统版本和 Build、受限机型、硬件与进程架构、Rosetta 状态、固定宿主类别、运行位置类别；每项单独标记取得状态 |
| 生命周期 | 固定启动、退出请求、休眠、唤醒、锁屏及会话暂停/恢复阶段 |
| 连接 | business / check 来源、transport / store 层、固定阶段和请求类型、各层独立连接代次、结果码、毫秒耗时、重试次数及等待、退出状态 |
| 任务 | 随机会话域、匿名 task/turn/file 代号、身份来源及关联可信度、监测代次、扫描批次、实际读取字节/偏移、固定生命周期及成员变化原因、范围受限的发现观察、分页成员快照与检查点 |
| 任务消费 | 快照 ID、实际输入任务数、固定呈现与紧凑显示规则、消费者、接收/请求绘制/跳过动作、呈现修订和原因；实体可见性未知 |
| 显示 | Touch Bar / notch / floating、固定动作/模式/原因/结果、可选窗口可见状态 |
| 升级与恢复 | 随机 updateSessionID、固定生产者角色、会话加序号 eventID、受限来源/目标/运行版本与 Build、固定执行阶段和分模块恢复观察 |
| 存储缺口 | 固定原因、数量、首次及末次时间 |
| 组件失败 | 固定组件和失败分类，不包含错误正文 |

事件 API 不接受任意字典或自由字符串。禁止邮箱、账号、凭据、实际额度和 Token 数值、任务/轮次原始 ID、正文、标题、工具参数、原始响应或 stderr、完整路径和设备序列号。已有自由文本系统日志也改为同一类型化入口；关闭记录后停止这些辅助输出。

## 升级、重启与恢复

支持本协议的来源版本会在退出前准备受保护交接状态，并尽力刷新日志；退出协调共享一个最多 3 秒的截止时间。安装器记录其实际观察到的旧进程退出、备份、替换、新版启动回执、超时和回退步骤。独立进度助手仅记录自身观察到的安装进程中断或迟到回执。诊断失败不改变安装或回退判断。

新版通过既有受校验参数接续；没有参数时，只接受诊断区内未完成、路径及版本匹配且唯一的受保护交接条目。歧义不按“最新”强行关联。进程身份包括真实版本及 Build；目标身份来自已验证的安装包。随机升级 ID 仅用于本次升级对照。

安装回执、业务连接、任务监测、明确的新任务开始、状态聚合、主线程接收和显示请求分别报告。没有新任务时不能声称已验证任务识别。重启后读取历史仅属于恢复后观察；HUD 停机期间没有业务采集。宿主是否保持同一进程目前保留未知，不以相同版本推断。

摘要只使用选定范围内冻结的事件。若同次升级还有范围外事件，会提示重新选择范围；不会暗中加入。退出观察和新版开始记录具有可比较的时间时展示两者间的观察空窗，不把它当作完整停机时长；缺一侧或时钟不一致则标未知。不同进程的单调时钟不能相减。

首次从没有诊断能力的旧版升级，旧版安装脚本和助手也没有本协议能力。新版无法补回这些不存在的记录；回退到不支持协议的旧版同样不能记录恢复接续。未知协议或事件被安全跳过并列为缺口，不将原始 JSON 复制进包。

固定诊断目录内的 `updates/<UUID>/handoff.json` 仅供无参数启动定位受保护更新通道，包含最少本地路径；它不进入事件、摘要或 ZIP，受相同期限及容量约束。清除诊断不会删除原安装目录的 `previous.app`、`install.log`、恢复状态或 `RECOVERY.txt`。这些材料可能含本地路径，须单独审阅。

## 逐任务追踪与解释边界

普通日志和 Hooks 共用连续日志读取器、分页任务发现和生命周期引擎。读取预算限制单次工作量，不会通过跳过未读字节来清空任务状态。诊断记录包含匿名任务、读取位置、状态转换原因、计数成员变化和显示快照编号，可用于核对同一快照如何到达不同显示端。

读取失败、日志缺失、来源覆盖不完整和快照被跳过分别记录。诊断能解释应用已观察到的证据，不能证明所有桌面任务都在覆盖范围内，也不能仅凭历史活跃状态证明任务仍在执行。任务身份与事件内容经过字段白名单处理，导出包不包含原始会话标识、提示词、工具参数或完整路径。

复现与回归入口包括 `scripts/test-diagnostic-logging.sh`、`scripts/test-diagnostic-task-trace.sh` 和 `scripts/test-unified-diagnostic-task-trace.sh`。隔离测试不替代真实设备显示、完整升级或长期能耗验证。
