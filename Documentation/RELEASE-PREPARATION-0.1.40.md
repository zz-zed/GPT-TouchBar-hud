# v0.1.40 发布准备

2026-10-06。目标版本 **0.1.40 / Build 43**，接续已发布的 v0.1.39 / Build 42。本版修复额度连接恢复、更新进度窗口退出后的命令轮询收尾、额度窗口分类，并让 app-server 初始化读取当前构建版本。版本元数据和用户说明与功能代码一起进入待发布提交。

## 本地验证

- 额度与连接状态 52 项、连接及展示 57 项、连接诊断 61 项、更新进度 223 项、更新策略 82 项、隔离安装 42 项检查通过。
- 真实客户端与 Store 使用自有测试子进程验证意外退出后自动恢复额度，停止监测后没有旧回调继续发布。
- 失败及取消结果关闭后停止轮询，重新打开恢复命令通道；校验故障注入验证同会话重试被拒绝、原应用不变。准备后期已有禁止重试的策略，未扩大安装目录或回退流程。

- 具体检查入口及本地边界见 [工程修复记录](ENGINEERING-FIXES-2026-10-06.md)。正式双架构回归与安装包由同一源码提交的 main CI 生成。

## 发布门禁

1. 提交并推送本版源码、版本及说明到 main，等待同一完整 SHA 的四个回归作业和两个打包作业全部成功。
2. 将 `v0.1.40` 注释标签固定到该提交；发布工作流复用并核验同一构建 run、attempt 的双架构产物。
3. 确认公开 Release 为 Latest、非草稿、非预发布，说明与标签提交中的 `RELEASE_NOTES.md` 一致。
4. 使用 `scripts/verify-public-release.py` 独立下载四份附件，核验源码及构建来源、大小、SHA-256、清单、DMG 完整性与只读挂载、版本、架构、macOS 11.0 最低系统标记、严格签名及首次打开助手 CDHash 绑定。

本文件记录准备阶段，不能作为正式发布完成的证据。真实宿主长期使用、休眠唤醒、真实 macOS 11、实体 Touch Bar / 刘海及正式安装路径的升级重启仍需相应设备验收。安装包为 ad-hoc 签名，未经 Apple 公证；发布不会自动替换本机已安装应用。
