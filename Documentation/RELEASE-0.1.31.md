## 本次变化

修复普通日志模式下任务完成提示结束后变成问号的问题。完成反馈持续约 4 秒，再恢复中性；仍有已确认执行中任务时继续显示数量。局部未知记录和整体监测故障只保留内部诊断，不单独向用户呈现。首次扫描与重启不回放历史完成提示，终态后的统计事件不重新激活任务。中性仅表示当前未检测到执行中任务，不能推断所有任务已完成。Hooks 语义保持原样。

README 同步整理使用说明与真实电脑效果示意。本次未改名，未引入此前取消的更新检查替代方案。
