## 菜单栏

应用以菜单栏配件运行，不在 Dock 常驻。点击菜单栏后，顶部汇总额度、任务状态、重置或到期时间、昨日 / 累计 Token、点数和更新时间，下方提供操作。

菜单栏内容有四种选择：

| 选项 | 表现 |
| --- | --- |
| 自动 | 刘海面板或桌面浮窗显示时只保留状态图标；面板隐藏后显示一项主要额度。 |
| 仅图标 | 始终只显示状态图标。 |
| 单额度 | 固定显示一项主要额度，不随面板可见性切换。 |
| 完整额度 | 显示完整额度信息，不随面板可见性切换。 |

完整额度可能显示为 `5h 85%  W 80%`。没有 5 小时窗口、但提供完整重置次数的账号，可能显示为 `重置3  W 96%`。这是数据差异，不是为每个账号补齐相同字段。

| 菜单项 | 用途 |
| --- | --- |
| 刷新额度 | 刷新额度，并在最短间隔允许时刷新 Token；刷新中禁用重复点击。 |
| 显示状态面板 / 隐藏状态面板 | 控制当前状态面板；隐藏状态独立保存。 |
| 收起详情 | 返回选定的刘海常驻形态。 |
| 显示形式 | 自动、刘海融合或桌面浮窗；无有效刘海区域时回退桌面浮窗。 |
| 菜单栏内容 | 自动、仅图标、单额度或完整额度。 |
| Touch Bar 常驻 | 开启或关闭跨 App 常驻额度条。 |
| 设置… | 打开独立设置窗口，快捷键为 `⌘,`。 |
| 新版本提醒 / 检查更新… | 查看新版本或手动检查更新；菜单同时显示当前版本和构建号。 |
| 退出 | 结束本工具，本轮宿主会话内不再自动拉起。 |

## 刘海面板

### 常驻形态与展开详情

**默认是额度预览态 Peek，不是先进入 Compact。** 该默认值只适用于未保存过常驻形态偏好的用户。

| 形态 | 平时看到什么 | 如何操作 |
| --- | --- | --- |
| 额度预览态 Peek（默认） | 额度与重置时间。 | 点击向下展开详情。 |
| 静止态 Compact（可选） | 刘海两侧的应用与任务指示器。 | 悬停进入 Peek，点击展开详情。 |
| 展开详情 Expanded | “额度 / 活动 / 用量”内容。 | 可以切换分页、滚动长内容，使用底部刷新、设置、隐藏与收起。 |

在“设置 → 通用 → 刘海常驻形态”中选择 Compact 或 Peek。离开面板或收起详情后返回所选常驻形态；任务变化不会自动展开面板。

### 自动适配、隐藏与多屏

未保存显示形式时，应用自动选择有效刘海屏；没有有效刘海区域时使用桌面浮窗。首次识别刘海且尚未保存显示 / 隐藏选择时直接显示面板；无刘海时桌面浮窗默认隐藏。已经隐藏的面板保持隐藏。

在菜单栏“显示形式”中手动选择后，重启和屏幕变化不会覆盖偏好；重新选择“自动”可恢复自动适配。显示形式、面板是否隐藏、刘海常驻形态是不同设置。

面板会稳定选择具有有效刘海区域的屏幕。无有效刘海几何或在 macOS 11 上运行时回退桌面浮窗，但保留刘海偏好；接回有效刘海屏后恢复。菜单和设置都能重新显示隐藏面板，再次双击已运行的应用可打开设置。

刘海面板始终为黑色不透明外观；桌面浮窗的颜色和透明度独立。锁屏 / 休眠时面板暂时隐藏，恢复后仍尊重用户的可见性选择。

### 使用边界

外壳、内容裁剪和点击判断共用实际动画轮廓；摄像头区域、透明角落和外部装饰不接收点击，外部点击可传给下层窗口。界面适配减少动态效果、降低透明度和低电量设置。

刘海宽度与安全区高度取自系统，双翼视觉高度另行校准，并不代表已精确测量硬件圆角或完成实体接缝校准。双翼和展开面板可能占用菜单栏空间。

实体接缝、透明角落点击穿透、全屏、自动隐藏菜单栏、锁屏 / 唤醒、多屏切换和拥挤菜单栏仍需真机验证。出现问题时可切换为桌面浮窗。实现与验证入口见[原生刘海面板](NotchIsland/README.md)。

## 桌面浮窗

从菜单栏“显示状态面板”打开，以单行胶囊显示额度和任务状态，宽度随内容自动伸缩。例如：

```text
执行中 2   ● 5h 85%   ● 7d 80%   ↻
```

没有 5 小时窗口而有重置次数时，可能显示为：

```text
● 重置 3次   ● 7d 96%   ↻
```

`↻` 用于刷新；刷新中显示等待图标并禁用重复操作，失败时显示错误图标和提示。面板没有退出按钮，通过菜单栏“隐藏状态面板”隐藏，或在浮窗右键菜单中选择隐藏；退出整个工具请使用菜单栏“退出”。

青绿色、黄色和红色状态点分别表示较充足、中等和较低的剩余额度；重置次数使用青色。悬停可查看任务详情或刷新提示，完整的重置 / 到期时间、Token 与点数汇总位于菜单栏详情。

右键菜单也提供刷新与设置。显示面板、内容宽度变化和拖动结束时会校正可用屏幕边界。开启系统“减少透明度”或“提高对比度”后，浮窗使用不透明背景和内容，并增强边框。

## Touch Bar

仅配备对应硬件且系统接口可用时使用。默认开启“设置 → Touch Bar → Touch Bar 常驻”，菜单栏也有同名开关。

额度条占用左侧应用区域，切换到其他 App 后仍会重新呈现；右侧保留系统原有的亮度、音量等控制项。展开系统控制条时，Token 区域会被系统覆盖，收起后恢复。

**常驻会覆盖其他 App 在左侧的 Touch Bar 快捷按钮。** 需要使用这些按钮时，关闭常驻即可释放系统级额度条。关闭常驻后，仍可通过点击已显示的面板，使用与当前 App 焦点绑定的普通 Touch Bar 模式。

信息列随内容计算宽度，没有点数时不预留空列；有点数时仍保留额度进度条。中文日期精确到分钟：重置次数旁的日期表示到期时间，额度旁的日期表示重置时间。Touch Bar 省略“到期 / 重置”后缀，完整含义可在菜单栏详情中查看。

隐藏状态面板不影响 Touch Bar 常驻。普通状态不显示额外关闭按钮，退出应用仍使用菜单栏。

常驻使用经过运行时签名检查的 AppKit 私有 system-modal 接口。公开 API 只能沿当前 App 焦点响应链显示 Touch Bar；私有接口缺失或签名不兼容时，常驻开关不可用，保留普通焦点绑定模式。

## 设置窗口

| 分页 | 内容 |
| --- | --- |
| 通用 | 显示形式、面板可见性、刘海常驻形态、菜单栏内容、语言、任务状态显示。 |
| 外观 | 桌面浮窗颜色、背景与文字不透明度；实时预览并即时保存，数值越高越不透明。 |
| Touch Bar | 控制常驻；系统接口不可用时禁用开关并说明原因。 |
| 实验 | 打开默认关闭的 Hooks 配置审阅与应用流程。 |
| 更新 | 控制自动检查，查看最近成功状态、新版本提醒及手动检查入口。 |

语言选择影响额度与任务信息，导航和设置保持中文。中文用量采用“万 / 亿”，英文采用 K / M / B / T；重置次数的到期时间精确到分钟。升级保留已有外观偏好。

## 任务状态与可选 Hooks

“设置 → 通用 → 显示任务状态（实验性）”默认开启。关闭后停止任务日志读取，不影响额度和账号 Token 数据。

默认日志模式下：菜单栏闪电图标以蓝色表示执行中、绿色表示最近完成、灰色表示未知；空闲或关闭提示时使用系统中性色，额度文字不随图标变色。Touch Bar 的应用图标角标使用蓝色数字、绿色 `✓` 或灰色 `?`；蓝色运行角标有轻微呼吸动画，系统开启“减少动态效果”时保持静态。

浮窗打开后显示同一份状态摘要，但任务变化不会自动弹出浮窗。执行中优先展示；最近完成提示保留 30 秒，明确中止的任务不显示完成。全部空闲时隐藏状态摘要；仍有未知任务时保留 `?`。

本功能不是全账号任务管理器，也不提供目标完成判定、失败识别或百分比进度。日志扫描范围、刷新间隔和未知状态判断见[数据与隐私说明](DATA-AND-PRIVACY.md#任务状态的读取与判断边界)。

Hooks 模式默认关闭，普通使用无需启用。进入“设置 → 实验”的 Hooks 配置窗口后，必须审阅计划并明确应用，才会安装 helper、写入配置并启用；仅打开窗口不会写入。宿主仍需正常审阅和信任，新建或变更配置后可能需要重新信任并重新打开任务。

Hooks 区分执行中、已提交待核对、未知、覆盖范围和连接健康；连接正常不等于覆盖全部任务。新完成事件的提示约 4 秒后消失，刷新或隐藏重开不重播，同轮继续执行会撤销完成提示。额度与 Token 数据来源不变；关闭 Hooks 恢复默认日志模式，关闭总的任务状态开关才停止任务监测。

真实宿主执行、准确性、延迟与长期能耗尚未验收。关闭实验不删除已应用配置、备份或稳定 helper，清理见[卸载说明](UNINSTALL.md#启用过-hooks-时先清理配置)和[Hooks 专题](HOOKS-EXPERIMENT.md)。

## 自动启动与升级偏好

首次运行会注册当前用户的 LaunchAgent：

```text
~/Library/LaunchAgents/io.github.zz-zed.GPTTouchBarHUD.CodexLauncher.plist
```

ChatGPT / Codex 启动时自动打开本工具；宿主完全退出后本工具结束。若宿主仍运行时手动退出本工具，本轮会话内不会再次自动拉起；宿主完全退出后解除这次手动退出状态。

从旧项目版本升级时，应用迁移已有浮窗外观和 Touch Bar 常驻偏好，停用旧 LaunchAgent，并兼容旧版的手动退出标记，避免两个版本同时自动启动。

从 v0.1.29 升级时，原“刘海始终显示额度”复选框关闭对应 Compact、开启对应 Peek；已有选择继续保留。只有从未保存过该偏好时才默认 Peek。显示形式和隐藏状态不因常驻形态默认值改变而重置。
