# v0.1.33 发布准备

目标版本：0.1.33 / Build 36。用户已授权审查 v0.1.32 之后全部工作区改动、统一提交并正式发布。

## 变更范围

- 根据设备型号识别内置 Touch Bar，无硬件时隐藏设置页及菜单入口；未知型号读取结果保留入口，不改用户偏好与常驻运行策略。
- 设置页使用稳定标识，避免隐藏 Touch Bar 页后重置预告跳转或语言更新错位。
- 重置预告详情增加失焦、应用失活和外部点击关闭；跨入口打开时独立创建弹框，关闭旧窗口并隔离旧回调。
- 云端构建与发布分离：main 双架构测试、打包并保存来源清单；标签发布只复用同提交的成功产物，校验后公开。
- 固定正式版本说明格式，仅列用户可感知的新增功能、优化与注意事项。
- 纳入工作区原有三张未被引用的 Marketing 旧图片删除，不恢复已删除资源；这些文件可从 Git 历史找回。

## 验证边界

- 本地原生测试包含真实浮窗和菜单栏按钮锚点、注入焦点通知及鼠标事件，不等于真实菜单 tracking、跨 App 交互和实体 Touch Bar 的完整验收。
- 普通显示器可运行模拟刘海测试，不要求用户拥有刘海屏；不据此声称实体刘海硬件已验收。
- 未进行 macOS 11 实机验收或真实安装路径的自动更新端到端验证。
- 沿用 ad-hoc 签名，未经过 Apple 公证；不会安装或替换维护者当前运行的应用。

发布操作与恢复规则见 [构建与正式发布](RELEASING.md)。历史 v0.1.32 标签和公开附件保持不变。
